# Starting point: solid backend developer, new to distributed systems

Learner states they are a solid backend developer who is new to distributed systems. Assume comfort with SQL, HTTP services and production operations; do not assume knowledge of replication, consensus, isolation anomalies or failure models. Start Module 0 with a hands-on failure scenario (timeouts) rather than definitions.

## Implications
- Skip "what is a database/index" basics in Part I; go to mechanisms and trade-offs quickly.
- Anchor each lesson in a work-checkable action (the "Do this at work" section).
