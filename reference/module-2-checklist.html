Data models and query languages: rules and measured numbers

One page for design reviews. “Measured” = MySQL 8.0.46 on a small synthetic dataset; the shapes matter more than the digits. Scripts: experiments/mysql/.

Start here

  1. List the access patterns and how often each runs. Everything below depends on it. (If unknown, measure first.)
  2. For each shared fact: must it change everywhere at once, or is a copy a snapshot?
  3. Where does each rule live, and what plan will the data be read with?

  • Embed: read together, bounded, no independent life, snapshot semantics. Reference: shared, unbounded growth, independent updates.
  • Torn multi-document writes are a property of the engine (single-document atomicity only), not of the model. MySQL rows in one transaction are not torn. Without atomic multi-document commit, run Lesson 2's crash-point drill on every fan-out.
  • Many-to-many: junction table + indexes both ways + cascading foreign keys = one-statement delete, no half-linked states. Two-sided arrays = two writes per link (one torn state).
  • Drift: embed → add index → shared update fan-out → extract entity → application join. Give a genuine many-to-many its own home early.

MySQL JSON (Lessons 12, 14)

  • A JSON column cannot be indexed directly: index a generated column for a scalar path, or a multi-valued index (CAST(... AS UNSIGNED ARRAY)) for an array, queried with MEMBER OF.
  • An unindexed path predicate scans (EXPLAIN type ALL).
  • CHECK (JSON_SCHEMA_VALID(schema, doc)) rejects wrong-shaped documents at write (error 3819).
  • Verified on 8.0.46 against the 8.0 manual. Check your version's manual and support status.

Schema (Lesson 14)

  • “Schemaless” = implicit schema in code. One copy of the schema per reader.
  • Tolerant defaults turn shape changes into silent wrong answers; strict readers turn them into loud errors. Prefer loud.
  • Only database-enforced rules (types, NOT NULL, FK, CHECK) bind every writer.
  • Migrate by expand and contract: add optional → readers accept both → switch writers + backfill → make required + strict → remove old. Tolerance is for the middle.

Graph (Lesson 15)

  • Variable-depth questions need a recursive query or a graph engine. Walks of length h = dh; distinct people reached ≤ size of the graph.
  • Recursive CTE: UNION DISTINCT stops a cycle only if the carried columns repeat. Add a hop counter and it won't (error 3636 at the recursion limit); cap the hops. UNION ALL counts paths (measured: 6,561 rows at hop 8 for a 2,000-person graph).
  • Always bound hops on user-facing queries; use a visited set (or UNION DISTINCT without a counter).
  • Graph engine cost: another system, another language, data to keep in sync (outbox / change capture).
